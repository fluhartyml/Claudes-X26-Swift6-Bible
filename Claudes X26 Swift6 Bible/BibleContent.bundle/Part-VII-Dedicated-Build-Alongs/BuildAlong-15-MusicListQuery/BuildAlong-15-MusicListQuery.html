VII.15  Build-Along 15: MusicListQuery

Status: concept covered by Source Tours — no separate build-along.

AppleScript / ScriptingBridge querying of the Apple Music library on macOS is already demonstrated at production scale by two Source Tours in this Part. Rather than duplicate the material in a single-concept teaching app, readers are directed to study the production versions.

VII.15.1  Where to study this concept instead

VII.15.1 ¶1
  • Source Tour 21 — Cryo Playlist Manager — a Mac app that manipulates the Apple Music library + exports M3U playlists, using AppleScript / ScriptingBridge for the in-place library operations.
  • Source Tour 22 — NightGard Library Commander — a Mac app that cleans Apple Music library metadata in place using AppleScript, with MusicKit for read-only queries. Also shows the sandbox-with-temporary-exception-apple-events pattern.

VII.15.2  Why no standalone build-along

VII.15.2 ¶1 A single-concept "query the Music library" teaching app would be a thin demo by itself — it would either ship as a GitHub clone-and-build or need to be bulked up with features that would drift away from the original teaching point. Both Source Tours above already show the concept in a real shipping-product context. Duplicating the material in Part VII would waste the reader's time; pointing at the production tours is cleaner.

VII.15.3  Roster note

VII.15.3 ¶1 The slot number 15 stays reserved to preserve the roster's numbering. This entry acts as a signpost, not a build-along. Future revisions may repurpose slot 15 if a genuinely new concept emerges that deserves its own teaching app — but MusicListQuery as originally conceived is retired here.
