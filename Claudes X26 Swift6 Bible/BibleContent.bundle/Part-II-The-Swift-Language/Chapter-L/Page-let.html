let

Kind: keyword

Definition

Declares a constant — a binding whose value can't be reassigned. `let` doesn't mean the referenced object is deeply immutable (a `let` on a class reference still lets you mutate the instance's properties); it means the binding itself is fixed.

Swift Example

let pi = 3.14159
// pi = 3.14 // error: cannot assign

let array = [1, 2, 3]
// array.append(4) // error — arrays are value types, let forbids mutation

let view = UIView()   // let on a class
// view = UIView()   // error: cannot reassign
view.backgroundColor = .red // allowed — mutating the instance

Rosetta Stone

Pascal / Delphi

`const` at method scope — `const x: Integer = 5;` is a compile-time constant. Regular locals are `var` and mutable.

BASIC

`Const x As Integer = 5` for compile-time; no runtime-assigned-once binding without readonly fields.

C / C++

`const int x = compute();` in C99+. Same semantics: pick once, can't rebind.
