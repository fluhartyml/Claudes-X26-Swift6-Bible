@objc

Kind: attribute

Definition

Exposes a Swift declaration to the Objective-C runtime. Required for KVO, selectors, and dynamic dispatch through the ObjC runtime. Often combined with `dynamic`. Use only when you actually need ObjC interop.

Swift Example

import Foundation

class Button: NSObject {
    @objc func tap() { print("tapped") }
}

let b = Button()
b.perform(#selector(Button.tap))

Rosetta Stone

Pascal / Delphi

No cousin (Delphi has no Objective-C runtime).

BASIC

No cousin.

C / C++

Objective-C `@objc` is the target of Swift's attribute. Pure C has no runtime to expose to.
