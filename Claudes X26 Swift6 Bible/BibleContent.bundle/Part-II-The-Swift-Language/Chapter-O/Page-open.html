open

Kind: access-level

Definition

The most permissive access level — a declaration is visible AND subclassable / overridable from other modules. Use it for library types you explicitly intend consumers to extend.

Swift Example

open class Widget {
    open func draw() { print("base draw") }
}

// In another module:
// class Fancy: Widget {
//     override func draw() { print("fancy") }
// }

Rosetta Stone

Pascal / Delphi

Delphi classes are open for subclassing by default; `sealed` closes them. No stronger keyword for cross-module open.

BASIC

`Public` class with `Overridable` methods — nothing stronger in VB.NET.

C / C++

C++ has no framework/module boundary; `public` on a class member is the nearest analogue.
