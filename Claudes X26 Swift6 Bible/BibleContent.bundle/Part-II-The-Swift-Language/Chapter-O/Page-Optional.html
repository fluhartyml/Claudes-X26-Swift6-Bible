Optional

Kind: type

Definition

A generic enum with two cases, `.some(value)` and `.none`, used to model "a value, or nothing." Writing `T?` is shorthand for `Optional<T>`. Unwrap with `if let`, `guard let`, `??`, `map`, `flatMap`, or (cautiously) `!`.

Swift Example

let name: String? = "Ada"

if let n = name { print(n) }           // Ada
let length = name?.count ?? 0          // 3
let explicitly: Optional<Int> = .some(42)
print(explicitly ?? -1)                // 42

Rosetta Stone

Pascal / Delphi

`Nullable<T>` (Spring4D) or the `Variant` type for value types; classes can already be `nil`.

BASIC

`Nullable(Of T)` or `T?` for value types in VB.NET.

C / C++

No cousin. A pointer plus `NULL`, or a sentinel value, is the common idiom. C++17 `std::optional<T>`.
