override

Kind: modifier

Definition

A modifier on a method, property, or subscript that replaces the inherited version from a superclass. Swift requires `override` so you can't shadow a superclass member by accident.

Swift Example

class Animal { func speak() { print("...") } }
class Dog: Animal {
    override func speak() { print("woof") }
}

let d: Animal = Dog()
d.speak() // woof
