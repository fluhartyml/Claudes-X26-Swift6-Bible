operator

Kind: keyword

Definition

Declares a custom operator token at the top level. You must choose its fixity (`prefix`, `infix`, `postfix`) and, for `infix`, a precedence group.

Swift Example

prefix operator √

prefix func √ (x: Double) -> Double { x.squareRoot() }

print(√16) // 4.0

Rosetta Stone

Pascal / Delphi

`class operator Add(a, b: T): T` defines operator overloads.

BASIC

`Shared Operator +(a As T, b As T) As T` on a class.

C / C++

C++ `T operator+(const T&, const T&)`. Plain C has no operator overloading.
