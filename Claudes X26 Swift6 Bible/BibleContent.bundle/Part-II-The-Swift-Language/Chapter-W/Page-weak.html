weak

Kind: modifier

Definition

A capture or property modifier for a class reference that doesn't bump the reference count and becomes `nil` automatically when the referenced object is deallocated. Always Optional. Use it to break retain cycles.

Swift Example

class Parent {
    var child: Child?
}
class Child {
    weak var parent: Parent?
}

let p = Parent()
let c = Child()
c.parent = p
p.child = c // no cycle: parent is weak

Rosetta Stone

Pascal / Delphi

`[Weak]` attribute on a field under ARC (Delphi mobile). Same intent.

BASIC

`WeakReference(Of T)` wrapper. Always Optional-like (may be dead).

C / C++

No cousin in C. C++ `std::weak_ptr<T>` alongside `std::shared_ptr<T>`.
