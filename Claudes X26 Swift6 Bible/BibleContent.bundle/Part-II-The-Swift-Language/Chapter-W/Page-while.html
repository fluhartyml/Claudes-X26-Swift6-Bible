while

Kind: keyword

Definition

Runs its body repeatedly as long as the condition stays true. The condition is checked before every iteration, so the body may run zero times. Contrast with `repeat-while`, which always runs at least once.

Swift Example

var n = 10
while n > 0 {
    print(n)
    n -= 2
}
// 10 8 6 4 2

Rosetta Stone

Pascal / Delphi

`while cond do ... ;` — pre-test loop.

BASIC

`While cond ... End While` or `Do While cond ... Loop`.

C / C++

`while (cond) { ... }` — identical keyword.
