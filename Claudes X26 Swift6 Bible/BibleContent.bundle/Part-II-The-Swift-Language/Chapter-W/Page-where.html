where

Kind: keyword

Definition

Adds a constraint. On a generic parameter, it narrows allowed types. On a `case`, `for`, or `switch`, it adds a pattern guard. On a protocol extension, it restricts when the extension applies.

Swift Example

extension Collection where Element: Numeric {
    func total() -> Element {
        reduce(.zero, +)
    }
}

print([1, 2, 3].total()) // 6

for n in 1...10 where n.isMultiple(of: 3) {
    print(n)
}

Rosetta Stone

Pascal / Delphi

Generic constraints: `class(TFoo)` — constraint is positional and limited.

BASIC

`Of T As {New, Class, IFoo}` — constraint list on the type parameter.

C / C++

No cousin in C. C++ concepts (`requires`) are the modern match; SFINAE was the older workaround.
