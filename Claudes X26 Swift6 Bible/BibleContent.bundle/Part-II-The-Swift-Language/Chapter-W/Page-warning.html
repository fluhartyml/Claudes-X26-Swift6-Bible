#warning

Kind: directive

Definition

Emits a compile-time warning with the given message. Useful as a breadcrumb for work-in-progress code so you can't ship without noticing.

Swift Example

func placeholder() -> Int {
    #warning("TODO: implement real calculation")
    return 0
}

Rosetta Stone

Pascal / Delphi

`{$MESSAGE WARN 'text'}` compiler directive.

BASIC

`#Warning "text"` directive.

C / C++

`#warning text` (extension in GCC/Clang; standardized in C23).
