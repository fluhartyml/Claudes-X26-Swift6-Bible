var

Kind: keyword

Definition

Declares a mutable binding — you can reassign the variable and (for value types) mutate through it. Use `let` by default and promote to `var` only when you need mutation.

Swift Example

var count = 0
count += 1
print(count) // 1

var numbers = [1, 2, 3]
numbers.append(4)
print(numbers) // [1, 2, 3, 4]

Rosetta Stone

Pascal / Delphi

`var x: Integer;` — a mutable local. Identical role.

BASIC

`Dim x As Integer` — identical.

C / C++

`int x;` — mutable by default. Use `const int x = ...;` for immutability.
