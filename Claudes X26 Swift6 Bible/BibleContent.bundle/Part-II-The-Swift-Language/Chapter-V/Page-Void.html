Void

Kind: type

Definition

A typealias for the empty tuple `()`. A function that returns `Void` returns nothing meaningful; writing `-> Void` is optional since it's the default return type.

Swift Example

func log(_ s: String) -> Void { print(s) }

// Equivalent:
func log2(_ s: String) { print(s) }

let callback: () -> Void = { print("done") }
callback()

Rosetta Stone

Pascal / Delphi

`procedure` (no return value) is the role of Void. There's no `Void` type name you use directly.

BASIC

`Sub` (no return value) instead of `Function`.

C / C++

`void` — the same keyword for no return.
