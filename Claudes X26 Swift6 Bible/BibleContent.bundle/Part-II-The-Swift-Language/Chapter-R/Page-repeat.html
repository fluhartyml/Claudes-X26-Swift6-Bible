repeat

Kind: keyword

Definition

The loop-introducer in `repeat-while` — Swift's do-while. The body runs once, then the condition is checked; if true, the body runs again. Unlike `while`, the body always runs at least once.

Swift Example

var n = 0
repeat {
    print(n)
    n += 1
} while n < 3
// 0
// 1
// 2

Rosetta Stone

Pascal / Delphi

`repeat ... until cond;` — runs body, then checks condition. Same as `repeat-while` except inverted condition.

BASIC

`Do ... Loop While cond` — post-test loop.

C / C++

`do { ... } while (cond);` — same semantics as Swift's `repeat-while`.
