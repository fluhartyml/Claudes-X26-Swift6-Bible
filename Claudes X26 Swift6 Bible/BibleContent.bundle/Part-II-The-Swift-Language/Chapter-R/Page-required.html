required

Kind: modifier

Definition

A modifier on a class initializer that forces every subclass to implement it (unless the subclass also satisfies it via inheritance). Use it to ensure every subclass provides a particular way of being constructed.

Swift Example

class Shape {
    required init() { print("shape") }
}

class Circle: Shape {
    required init() { super.init(); print("circle") }
}

let c = Circle()
// shape
// circle

Rosetta Stone

Pascal / Delphi

No cousin. Abstract methods via `abstract` keyword force subclass implementation of methods, not constructors.

BASIC

`MustOverride` on a method. No required-constructor concept.

C / C++

No cousin. C++ constructors aren't inherited; each subclass writes its own by default.
