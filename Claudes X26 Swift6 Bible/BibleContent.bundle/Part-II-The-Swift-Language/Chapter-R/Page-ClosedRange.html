ClosedRange

Kind: type

Definition

A range that includes both endpoints, written `a...b`. Unlike `Range`, you can never have an empty `ClosedRange` — `a...a` contains one element.

Swift Example

let r = 1...5
print(r.count)     // 5
print(Array(r))    // [1, 2, 3, 4, 5]
print(r.contains(5)) // true

Rosetta Stone

Pascal / Delphi

Pascal subrange `1..5` (inclusive) is the lexical match.

BASIC

`Enumerable.Range(1, 5)` covers 1..5 inclusive.
