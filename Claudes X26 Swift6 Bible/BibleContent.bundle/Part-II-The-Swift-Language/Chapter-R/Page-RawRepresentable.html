RawRepresentable

Kind: protocol

Definition

A protocol for types that are interchangeable with an associated `RawValue` (often `Int` or `String`). Enums with a raw type get conformance automatically. Use `init?(rawValue:)` to create, `.rawValue` to extract.

Swift Example

enum Suit: String, CaseIterable { case hearts, diamonds, clubs, spades }

print(Suit.hearts.rawValue) // "hearts"
if let s = Suit(rawValue: "clubs") { print(s) } // clubs

Rosetta Stone

Pascal / Delphi

Enum-to-Integer conversions via `Ord(x)` and `T(IntVal)` casts. Not a protocol.

BASIC

`Enum` types with a base type (`Enum Foo : Short ... End Enum`) use `CInt(x)` and `CType(n, Foo)`.

C / C++

`enum` values ARE their underlying int by default. Cast is explicit: `(int)Color_Red`.
