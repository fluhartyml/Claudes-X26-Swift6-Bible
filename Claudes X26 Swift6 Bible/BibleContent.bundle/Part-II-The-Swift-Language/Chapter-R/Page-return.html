return

Kind: keyword

Definition

Exits the current function or method, optionally handing back a value. In single-expression functions, `return` is implicit and can be omitted.

Swift Example

func square(_ n: Int) -> Int {
    return n * n
}

// Equivalent single-expression form:
func cube(_ n: Int) -> Int { n * n * n }

print(square(3)) // 9
print(cube(3))   // 27

Rosetta Stone

Pascal / Delphi

Assign to implicit `Result` variable; `Exit;` returns. In modern Delphi: `Exit(value)`.

BASIC

`Return value` in a function.

C / C++

`return value;` — identical keyword.
