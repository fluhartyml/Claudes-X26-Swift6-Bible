Double

Kind: type

Definition

A 64-bit IEEE-754 floating-point type, Swift's default for non-integer numeric literals. Use `Double` when you need decimal values and don't specifically need the reduced precision of `Float`.

Swift Example

let pi: Double = 3.14159265358979
let area = pi * 5 * 5
print(area) // 78.53981...

let x = 0.1 + 0.2 // 0.30000000000000004 — floating-point truth
