Dictionary

Kind: type

Definition

An unordered collection of key-value pairs, written as `[Key: Value]`. Keys must be `Hashable`. Lookups return an `Optional<Value>` since the key may not be present.

Swift Example

var ages: [String: Int] = ["Ada": 30, "Max": 25]
ages["Zoe"] = 28

if let a = ages["Ada"] { print(a) } // 30

for (name, age) in ages.sorted(by: { $0.key < $1.key }) {
    print(name, age)
}

Rosetta Stone

Pascal / Delphi

`TDictionary<K, V>` in Delphi's Generics.Collections — hash-based, same ergonomics.

BASIC

`Dictionary(Of K, V)` in VB.NET — identical shape.

C / C++

No built-in in C (hash tables via uthash.h or custom). C++ has `std::unordered_map<K, V>`.
