@discardableResult

Kind: attribute

Definition

An attribute that suppresses the "result of call is unused" warning when callers ignore the return value. Use it for methods that mainly act for their side effect but also return something occasionally useful.

Swift Example

@discardableResult
func logAndReturn(_ message: String) -> String {
    print(message)
    return message
}

logAndReturn("hi") // no warning even though we ignore the return

Rosetta Stone

Pascal / Delphi

No cousin. Delphi doesn't warn on unused function results; the attribute would be a no-op.

BASIC

No cousin. VB.NET's compiler doesn't warn on unused return values.

C / C++

`__attribute__((warn_unused_result))` in GCC/Clang is the opposite: it WARNS on unused returns. No suppress flag; you just don't apply the attribute.
