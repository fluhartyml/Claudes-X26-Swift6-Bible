do

Kind: keyword

Definition

Starts a block. Used with `try`/`catch` to handle thrown errors, and on its own to introduce a nested scope (e.g. to limit the lifetime of shadowed bindings).

Swift Example

do {
    let data = try Data(contentsOf: URL(fileURLWithPath: "/tmp/missing"))
    print(data.count)
} catch {
    print("failed: \(error)")
}

Rosetta Stone

Pascal / Delphi

Delphi uses `try ... except` / `try ... finally`; there's no bare `do` block. `do` appears as part of `while ... do`.

BASIC

`Do ... Loop` in VB is the loop form; exception-handling is `Try`.

C / C++

`do { ... } while (cond);` is the post-test loop. For exception-like blocks C++ uses `try`.
