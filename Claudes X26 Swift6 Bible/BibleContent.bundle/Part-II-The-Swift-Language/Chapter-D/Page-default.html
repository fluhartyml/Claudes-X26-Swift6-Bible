default

Kind: keyword

Definition

The catch-all case in a `switch` statement, matched when no earlier case matches. Also the keyword for a default parameter value in a function declaration.

Swift Example

func greet(_ name: String = "world") {
    print("Hello, \(name)")
}
greet()          // Hello, world
greet("Michael") // Hello, Michael

switch 7 {
case 1: print("one")
case 2: print("two")
default: print("something else")
}

Rosetta Stone

Pascal / Delphi

`else` inside a `case ... of` statement. Default parameter values use `parameter: Type = value`.

BASIC

`Case Else` in `Select Case`. Default parameters: `Optional ByVal x As Integer = 0`.

C / C++

`default:` inside `switch`. Default parameters are a C++ feature: `void f(int x = 0);`.
