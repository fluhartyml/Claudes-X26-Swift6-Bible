get

Kind: accessor

Definition

Defines the read accessor of a computed property or subscript. Paired with `set` for read/write; stand-alone `get` (without `set`) defines a read-only computed property.

Swift Example

struct Rectangle {
    var width: Double, height: Double
    var area: Double {
        get { width * height }
    }
}

let r = Rectangle(width: 3, height: 4)
print(r.area) // 12.0

Rosetta Stone

Pascal / Delphi

`function GetFoo: T;` paired with a `property`. Same role.

BASIC

`ReadOnly Property Foo As T` with a `Get` block.

C / C++

No properties in C. C++ uses regular member functions (`T getFoo() const`).
