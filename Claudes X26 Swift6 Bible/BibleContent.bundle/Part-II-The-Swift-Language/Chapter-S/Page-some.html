some

Kind: keyword

Definition

Marks an opaque type — the function returns "some specific type conforming to the given protocol, but the caller doesn't get to know which type." The concrete type is fixed per call site; SwiftUI's `some View` is the standard example.

Swift Example

protocol Shape { func area() -> Double }
struct Square: Shape { let side: Double; func area() -> Double { side * side } }

func unitShape() -> some Shape {
    Square(side: 1)
}

let s = unitShape()
print(s.area()) // 1.0
