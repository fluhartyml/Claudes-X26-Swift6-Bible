Set

Kind: type

Definition

An unordered collection of unique `Hashable` values. Lookups, inserts, and membership tests are O(1) on average. Use Set when order doesn't matter and uniqueness does.

Swift Example

var tags: Set<String> = ["swift", "ios"]
tags.insert("macos")
tags.insert("swift") // duplicate — ignored
print(tags.count)    // 3
print(tags.contains("ios")) // true

Rosetta Stone

Pascal / Delphi

Pascal `set of Byte` / `set of TMyEnum` is bit-packed (max 256 elements). `TDictionary<K, Boolean>` emulates a general set. Spring4D has `ISet<T>`.

BASIC

`HashSet(Of T)` in VB.NET.

C / C++

No cousin. C++ `std::set<T>` (ordered) or `std::unordered_set<T>` (hashed).
