Sequence

Kind: protocol

Definition

The most abstract protocol for things you can iterate once. A `Sequence` has a `makeIterator()` and yields elements. `Collection` refines it with the ability to iterate multiple times and index.

Swift Example

struct Countdown: Sequence, IteratorProtocol {
    var n: Int
    mutating func next() -> Int? {
        guard n > 0 else { return nil }
        defer { n -= 1 }
        return n
    }
}

for x in Countdown(n: 3) { print(x) }
// 3
// 2
// 1
