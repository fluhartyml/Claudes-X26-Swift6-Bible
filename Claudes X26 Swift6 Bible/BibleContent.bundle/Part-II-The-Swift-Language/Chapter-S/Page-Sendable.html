@Sendable

Kind: attribute

Definition

An attribute on a closure parameter declaring the closure must be `Sendable` — safe to hand across actor and task boundaries. The compiler then checks that any captures are themselves `Sendable`.

Swift Example

func dispatch(_ work: @Sendable @escaping () -> Void) {
    Task.detached { work() }
}

dispatch { print("ran on another task") }
