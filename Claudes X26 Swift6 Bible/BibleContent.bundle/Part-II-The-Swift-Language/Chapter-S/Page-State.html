@State

Kind: attribute-swiftui

Definition

A SwiftUI property wrapper that owns a piece of transient view-local state. Writes trigger the view to re-render. Use `@State` only inside views and only for types the view fully owns.

Swift Example

struct Counter: View {
    @State private var n = 0
    var body: some View {
        Button("tap \(n)") { n += 1 }
    }
}
