String

Kind: type

Definition

A Unicode-correct, value-typed string. Iterating a `String` yields `Character` values (which may each be composed of multiple Unicode scalars). String literals use double quotes; multi-line literals use triple quotes.

Swift Example

let name = "Ada"
let greeting = "Hello, \(name)!"
print(greeting) // Hello, Ada!

let multi = """
    line one
    line two
"""

print(name.count) // 3

Rosetta Stone

Pascal / Delphi

`string` / `UnicodeString` (UTF-16). Grapheme-cluster iteration needs manual work via the `Character` unit.

BASIC

`String` (UTF-16, immutable).

C / C++

`char *` / `char[]` (null-terminated, byte-sequence). C++ `std::string` (byte-sequence) and `std::u16string` / `std::u32string`.
