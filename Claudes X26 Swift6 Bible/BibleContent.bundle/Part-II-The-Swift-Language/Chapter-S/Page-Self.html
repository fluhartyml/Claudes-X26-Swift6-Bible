self

Kind: keyword

Definition

The current instance within a method (lowercase-s). You only need to write it when disambiguating from a parameter of the same name or capturing in a closure.

Swift Example

struct Player {
    var score: Int
    mutating func add(_ score: Int) {
        self.score += score // self disambiguates from parameter
    }
}

var p = Player(score: 10)
p.add(5)
print(p.score) // 15

Rosetta Stone

Pascal / Delphi

`Self` — identical meaning, capitalized.

BASIC

`Me` — the current instance reference.

C / C++

`this` in C++. Not available in plain C (structs have no methods).
