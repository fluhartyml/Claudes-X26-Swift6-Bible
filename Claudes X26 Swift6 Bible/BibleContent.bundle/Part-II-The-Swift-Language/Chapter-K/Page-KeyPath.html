KeyPath

Kind: type

Definition

A type-safe, compiler-checked reference to a property of a type, written `\Type.property`. Use key paths with `map`, `sorted(by:)`, SwiftUI bindings, and property observation APIs.

Swift Example

struct User { let name: String; let age: Int }

let users = [User(name: "Ada", age: 30), User(name: "Max", age: 25)]
let names = users.map(\.name)
let byAge = users.sorted { $0.age < $1.age }
print(names)                  // ["Ada", "Max"]
print(byAge.first?.name ?? "") // Max

Rosetta Stone

Pascal / Delphi

No cousin in Delphi. RTTI traversal (`TRttiType.GetField`) by string name is the runtime equivalent — but unchecked.

BASIC

VB.NET `Expression(Of Func(Of T, TProp))` lambdas capture member access similarly, but they're runtime ASTs, not keypath values.

C / C++

No cousin. C++ pointer-to-member (`int Foo::*p = &Foo::x;`) is the conceptual match.
