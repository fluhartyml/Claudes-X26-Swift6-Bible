@autoclosure

Kind: attribute

Definition

An attribute that automatically wraps an argument expression in a closure, delaying its evaluation until the closure is called. Commonly used to make short-circuit and assertion-like APIs read naturally.

Swift Example

func assertPositive(_ value: @autoclosure () -> Int) {
    let v = value()
    precondition(v > 0, "must be positive")
}

assertPositive(5)          // no parentheses — looks like a value
// assertPositive(-1)      // would trap

Rosetta Stone

Pascal / Delphi

No cousin. Delphi evaluates arguments eagerly; for lazy evaluation you pass an explicit anonymous method: `procedure of object`.

BASIC

No direct cousin. Pass a `Func(Of T)` explicitly to get deferred evaluation.

C / C++

No cousin. Use a function pointer / lambda as the argument and call it inside the function to defer evaluation.
