as

Kind: keyword

Definition

A type-cast operator with three flavors: `as` for guaranteed upcasts checked at compile time, `as?` for a conditional downcast that returns an optional, and `as!` for a force downcast that traps if the types don't match.

Swift Example

let values: [Any] = [1, "two", 3.0]

for v in values {
    if let s = v as? String {
        print("string: \(s)")
    }
}

let anyNumber: Any = 42
let n = anyNumber as! Int // trap if wrong

Rosetta Stone

Pascal / Delphi

`as` in Delphi is nearly identical (`obj as TSub`) — raises EInvalidCast on failure. The `is` operator tests first.

BASIC

`CType(x, T)` or `DirectCast(x, T)` in VB.NET. `TryCast` is the nil-on-fail sibling of Swift's `as?`.

C / C++

C uses explicit casts: `(Type)value`. No runtime check. C++ adds `dynamic_cast<T*>(p)` which is the closest match to `as?`.
