await

Kind: keyword

Definition

Marks the point where an async operation may suspend. Required in front of every call to an `async` function, an async property access, or an actor method call from outside the actor. The compiler won't let you forget it.

Swift Example

func load() async -> String { "done" }

Task {
    print("before")
    let result = await load()
    print(result) // done
    print("after")
}

Rosetta Stone

Pascal / Delphi

Delphi 11+ has `await` inside async functions.

BASIC

Same keyword: `Await someTask` in VB.NET.

C / C++

C++20 `co_await`. Plain C has no built-in await.
