Array

Kind: type

Definition

An ordered, random-access collection of values of the same type, written as `[Element]`. Arrays are value types — assigning or passing an array makes a copy (with copy-on-write, so no work happens until a copy is actually mutated).

Swift Example

var primes: [Int] = [2, 3, 5, 7]
primes.append(11)
print(primes.count)     // 5
print(primes[0])        // 2

let doubled = primes.map { $0 * 2 }
print(doubled)          // [4, 6, 10, 14, 22]

Rosetta Stone

Pascal / Delphi

Delphi's `TArray<T>` (dynamic array) and `array of T` match `[Element]` closely. Zero-indexed, reference-managed.

BASIC

VB's `Dim arr() As Integer` and `ReDim Preserve`. Simpler API, same concept.

C / C++

`int arr[N]` (fixed) or `malloc`'d pointer-to-array (dynamic). No bounds checking. C++ adds `std::vector<T>` which is the closer analogue.
