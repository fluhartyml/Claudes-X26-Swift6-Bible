Any

Kind: type

Definition

The universal type — an instance of `Any` can hold a value of any type at all, including class types, struct types, enums, function types, and optionals. Use it sparingly; reaching for `Any` usually means the type system has something more specific to offer.

Swift Example

let bag: [Any] = [42, "hello", 3.14, true]

for item in bag {
    if let n = item as? Int {
        print("int: \(n)")
    } else if let s = item as? String {
        print("string: \(s)")
    }
}

Rosetta Stone

Pascal / Delphi

Similar to `TObject` in Delphi — the root of the class hierarchy, can hold any class reference. Not quite the same for value types.

BASIC

Visual Basic's `Object` class serves this role via boxing.

C / C++

`void *` with explicit casts, or C++ `std::any`. Swift's `Any` is safer because cast attempts are checked via `as?`.
