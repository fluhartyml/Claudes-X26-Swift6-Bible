Comparable

Kind: protocol

Definition

A protocol for types that define a total ordering via `<`. Conforming types get `>`, `<=`, `>=`, `sorted()`, `min()`, `max()`, and range expressions for free. Most built-in value types conform (`Int`, `Double`, `String`, `Date`).

Swift Example

struct Score: Comparable {
    let value: Int
    static func < (a: Score, b: Score) -> Bool { a.value < b.value }
}

let scores = [Score(value: 88), Score(value: 42), Score(value: 95)]
print(scores.min()!.value) // 42
print(scores.sorted().map(\.value)) // [42, 88, 95]

Rosetta Stone

Pascal / Delphi

Delphi's `IComparer<T>` interface with a `Compare(a, b) : Integer` method.

BASIC

`IComparable(Of T)` in VB.NET with `CompareTo(other) As Integer`.

C / C++

No cousin in C. C++ has `operator<` (and C++20 `<=>` for three-way comparison) plus `std::less<T>`.
