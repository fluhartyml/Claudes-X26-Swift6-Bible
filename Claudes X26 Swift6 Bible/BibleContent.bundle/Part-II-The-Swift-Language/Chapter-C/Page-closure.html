closure

Kind: concept

Definition

A self-contained block of code you can pass around as a value. Closures capture any variables they reference from their surrounding scope. Functions, methods, and closures are all the same category in Swift — first-class values with a function type.

Swift Example

let add: (Int, Int) -> Int = { a, b in a + b }
print(add(2, 3)) // 5

let names = ["Zoe", "Ada", "Max"]
let sorted = names.sorted { $0 < $1 }
print(sorted) // ["Ada", "Max", "Zoe"]

Rosetta Stone

Pascal / Delphi

`procedure of object` (bound method) and anonymous methods (`procedure begin ... end`) are Delphi's closures.

BASIC

`Function(x) x * 2` lambda expressions in VB.NET.

C / C++

No closures in C. C++ lambdas (`[capture] (args) { body }`) and function objects serve the role.
