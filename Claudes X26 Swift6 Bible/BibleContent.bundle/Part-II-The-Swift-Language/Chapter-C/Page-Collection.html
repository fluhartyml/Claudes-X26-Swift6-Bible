Collection

Kind: protocol

Definition

A protocol for types that let you iterate multiple times over finite elements and access them by position. Arrays, Strings, Dictionaries, Sets, and Ranges all conform. Conforming types inherit dozens of algorithms (`map`, `filter`, `reduce`, `first(where:)`, etc.).

Swift Example

func middle<C: Collection>(_ c: C) -> C.Element? where C.Index == Int {
    guard !c.isEmpty else { return nil }
    return c[c.count / 2]
}

print(middle([10, 20, 30]) ?? 0) // 20

Rosetta Stone

Pascal / Delphi

`IEnumerable<T>` plus index-based collection interfaces like `IList<T>`, `TList<T>` in Delphi.

BASIC

VB.NET's `IEnumerable(Of T)` + `ICollection(Of T)` + `IList(Of T)`. Cumulative protocols.

C / C++

No cousin in C. C++'s concepts-based iterator hierarchy (`std::ranges::sized_range`, `std::ranges::random_access_range`) is the closest analogue.
