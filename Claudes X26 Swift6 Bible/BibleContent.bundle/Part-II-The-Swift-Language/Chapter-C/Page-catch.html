catch

Kind: keyword

Definition

Handles an error thrown from a `do` block. Each `catch` binds the error (by default as `error`) and can match specific cases with patterns. A `do/catch` must exhaustively handle the error types its body can throw.

Swift Example

enum ParseError: Error { case bad, empty }

func parse(_ s: String) throws -> Int {
    if s.isEmpty { throw ParseError.empty }
    guard let n = Int(s) else { throw ParseError.bad }
    return n
}

do {
    let n = try parse("42")
    print(n)
} catch ParseError.empty {
    print("empty input")
} catch {
    print("other: \(error)")
}

Rosetta Stone

Pascal / Delphi

`except on E: ExceptionType do ... end;` is Delphi's shape.

BASIC

`Catch ex As Exception` inside a `Try` block.

C / C++

Plain C has no exceptions; use `setjmp` / `longjmp` for rough control. C++ uses `catch (const std::exception &e)`.
