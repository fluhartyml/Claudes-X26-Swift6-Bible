concurrency

Kind: concept

Definition

Swift's model for running multiple things at the same time without corrupting shared state. The modern Swift concurrency system (introduced in Swift 5.5, made strict by default in Swift 6) is built on four pillars: async/await for ergonomic asynchronous code, Task for the concurrency unit, actor for safe shared state, and Sendable for the type-system rule that data crossing concurrency boundaries is safe to move.

Swift 6 enforces concurrency safety at compile time. The compiler tracks which code runs on which actor, refuses to let you smuggle non-Sendable values across boundaries, and surfaces races as build errors before they become runtime crashes. That strictness is the headline change of the Swift 6 era.

Swift Example

actor Counter {
    private var value = 0
    func bump() { value += 1 }
    func read() -> Int { value }
}

func runManyBumps() async {
    let counter = Counter()
    await withTaskGroup(of: Void.self) { group in
        for _ in 0..<1000 {
            group.addTask { await counter.bump() }
        }
    }
    print(await counter.read())   // 1000 — no lost updates
}

The actor serializes access to value automatically. await marks each suspension point. withTaskGroup creates structured concurrency — every child task is guaranteed to finish before the group returns. None of this requires explicit locks.

Rosetta Stone

Pascal / Delphi

Delphi has TThread, TCriticalSection, and parallel programming via the PPL (Parallel Programming Library) — explicit thread spawning with manual synchronization. No language-level safety guarantee; you write the locks and you live with the bugs you introduce.

BASIC

VB.NET has Async/Await + the Task type, conceptually close to Swift's model but without actor isolation or Sendable compile-time checks. Older BASICs (Quick BASIC, GW-BASIC) were single-threaded by design — the program ran one statement at a time, period.

C / C++

C uses POSIX threads (pthread_create, pthread_mutex_lock) — bare-metal, error-prone. C++11 added std::thread, std::mutex, std::async, std::future, and C++20 added coroutines. None of these have Swift's compile-time data-race safety; you can still write a race in C++ and it'll compile cleanly.
