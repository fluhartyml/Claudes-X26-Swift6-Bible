continue

Kind: keyword

Definition

A control-flow statement that skips the rest of the current loop iteration and jumps to the next one. Like `break`, it can target a labeled loop to continue an outer level.

Swift Example

for n in 1...6 {
    if n.isMultiple(of: 2) { continue }
    print(n)
}
// prints 1 3 5
