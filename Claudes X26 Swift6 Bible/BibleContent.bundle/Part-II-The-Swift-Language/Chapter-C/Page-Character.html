Character

Kind: type

Definition

A single human-readable character, which may be made of one or more Unicode scalars (e.g. an emoji with a skin-tone modifier is one `Character`). Strings iterate as sequences of `Character`, not bytes or scalars.

Swift Example

let s = "Cafe\u{301}" // 'e' + combining acute
for c in s { print(c) }
// C
// a
// f
// é  (one Character: e + ́ )
print(s.count) // 4

Rosetta Stone

Pascal / Delphi

`Char` in Pascal is a single byte; Delphi's `Char` is a UTF-16 code unit. Neither matches Swift's grapheme-cluster Character.

BASIC

`Char` (UTF-16 code unit) in VB.NET. No grapheme-cluster type built in.

C / C++

`char` is one byte. `wchar_t` is a wide character (platform-dependent width). No grapheme-cluster support; use ICU.
