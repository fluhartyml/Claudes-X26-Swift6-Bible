convenience

Kind: modifier

Definition

A modifier on a class initializer that means "this init must delegate to another init of the same class, which eventually reaches a designated init." Convenience inits make common configurations simpler without the subclass having to override them.

Swift Example

class Color {
    let red: Double, green: Double, blue: Double
    init(red: Double, green: Double, blue: Double) {
        self.red = red; self.green = green; self.blue = blue
    }
    convenience init(gray: Double) {
        self.init(red: gray, green: gray, blue: gray)
    }
}

let c = Color(gray: 0.5)

Rosetta Stone

Pascal / Delphi

No explicit keyword. Delphi constructors can call other constructors directly.

BASIC

Similar concept; VB.NET lets one constructor call another via `Me.New(...)`.

C / C++

C has no constructors. C++ constructors can delegate (`Foo() : Foo(42) {}`) — no convenience/designated distinction.
