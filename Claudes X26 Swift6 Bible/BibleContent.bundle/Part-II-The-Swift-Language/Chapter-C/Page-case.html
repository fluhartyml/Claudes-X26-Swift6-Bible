case

Kind: keyword

Definition

Used in `switch` statements to match a pattern, in `enum` declarations to name one of the possible cases, and in `if case` / `for case` / `guard case` for pattern-matching outside `switch`.

Swift Example

enum Direction { case north, south, east, west }

let heading = Direction.east
switch heading {
case .north: print("up")
case .south: print("down")
case .east, .west: print("sideways")
}

Rosetta Stone

Pascal / Delphi

`case` in Pascal/Delphi's `case ... of` works similarly but matches only ordinals and ranges; no pattern matching.

BASIC

`Case` / `Case Is` / `Case To` inside `Select Case`.

C / C++

`case` inside `switch`. No associated-value destructuring; C falls through by default (the opposite of Swift's behavior).
