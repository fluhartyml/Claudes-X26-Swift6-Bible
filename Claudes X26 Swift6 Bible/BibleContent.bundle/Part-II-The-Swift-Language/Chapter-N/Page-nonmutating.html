nonmutating

Kind: modifier

Definition

A modifier on a property setter (inside a struct / enum) that promises the set operation doesn't change `self`. Useful when a computed setter writes to external storage rather than back into `self`.

Swift Example

struct Cache {
    nonmutating set(_ value: String) {
        UserDefaults.standard.set(value, forKey: "note")
    }
    init() {}
}

extension Cache {
    var note: String {
        get { UserDefaults.standard.string(forKey: "note") ?? "" }
        nonmutating set { UserDefaults.standard.set(newValue, forKey: "note") }
    }
}
