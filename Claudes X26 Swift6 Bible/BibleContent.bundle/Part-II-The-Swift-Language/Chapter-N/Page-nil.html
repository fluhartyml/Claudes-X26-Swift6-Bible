nil

Kind: literal

Definition

The absence of a value for an Optional type. `nil` is not zero, and it's not a pointer — it's a discriminator that says "this Optional is the `.none` case." Only Optional types can be `nil`.

Swift Example

var name: String? = "Ada"
name = nil

if name == nil {
    print("no name")
}

let count: Int? = nil
let doubled = count.map { $0 * 2 } ?? 0
print(doubled) // 0
