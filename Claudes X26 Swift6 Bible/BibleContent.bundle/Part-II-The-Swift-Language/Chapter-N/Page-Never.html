Never

Kind: type

Definition

The type of values that never exist. A function returning `Never` doesn't return — it aborts (`fatalError`), exits (`exit`), or loops forever. Because `Never` has no values, it converts to anything, which is useful in exhaustive switches.

Swift Example

func crash(_ reason: String) -> Never {
    fatalError(reason)
}

func pickNumber(_ n: Int) -> String {
    switch n {
    case 1: return "one"
    case 2: return "two"
    default: crash("unexpected \(n)")
    }
}

Rosetta Stone

Pascal / Delphi

No cousin. `procedure NoReturn; `... eventually calls `raise` or `Halt`.

BASIC

No cousin. Mark the method by convention; VB doesn't have a bottom type.

C / C++

`_Noreturn` (C11) / `[[noreturn]]` (C++11) function attribute — same intent.
