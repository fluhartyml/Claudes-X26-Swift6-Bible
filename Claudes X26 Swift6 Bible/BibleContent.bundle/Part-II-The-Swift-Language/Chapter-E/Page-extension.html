extension

Kind: keyword

Definition

Adds computed properties, instance / type methods, initializers, nested types, or protocol conformances to an existing type — even one you don't own. Extensions can't add stored properties.

Swift Example

extension Int {
    var isEven: Bool { self.isMultiple(of: 2) }
    func times(_ body: () -> Void) {
        for _ in 0..<self { body() }
    }
}

print(6.isEven) // true
3.times { print("hi") }

Rosetta Stone

Pascal / Delphi

Delphi class helpers (`TMyHelper = class helper for TExistingClass`) are the direct cousin. Same limitation: no stored fields.

BASIC

VB.NET extension methods via `<Extension>` attribute on a module. Adds methods only — no properties pre-.NET Framework 4.7.

C / C++

No cousin. C++ has no built-in extension mechanism; free functions that operate on a type fill a similar role.
