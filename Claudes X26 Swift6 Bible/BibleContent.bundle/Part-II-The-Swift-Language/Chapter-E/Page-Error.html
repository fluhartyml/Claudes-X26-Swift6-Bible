#error

Kind: directive

Definition

Emits a compile-time error with the given message. Use it inside a conditional-compilation branch to refuse to compile a configuration that isn't supported.

Swift Example

#if !canImport(Foundation)
    #error("This module requires Foundation")
#endif

Rosetta Stone

Pascal / Delphi

`{$MESSAGE ERROR 'text'}` directive.

BASIC

`#Error "text"` in VB.NET.

C / C++

`#error text` — identical intent.
