else

Kind: keyword

Definition

The alternative branch of an `if`, `guard`, or `if let` / `guard let`. With `if`, execution falls through to the `else` when the condition is false; with `guard`, the `else` must exit the current scope.

Swift Example

let n = 7
if n.isMultiple(of: 2) {
    print("even")
} else {
    print("odd")
}

func first(_ a: [Int]) -> Int {
    guard let v = a.first else { return -1 }
    return v
}
