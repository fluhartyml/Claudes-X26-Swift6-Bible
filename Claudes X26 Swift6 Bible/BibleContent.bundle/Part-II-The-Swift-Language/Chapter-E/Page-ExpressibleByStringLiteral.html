ExpressibleByStringLiteral

Kind: protocol

Definition

A protocol that lets a type be initialized directly from a string literal. Conform and Swift will let callers pass `"…"` anywhere your type is expected.

Swift Example

struct Tag: ExpressibleByStringLiteral {
    let raw: String
    init(stringLiteral value: String) { self.raw = value }
}

let t: Tag = "swift"
print(t.raw) // swift

Rosetta Stone

Pascal / Delphi

No cousin. Use an explicit constructor: `TFoo.FromString('...')`.

BASIC

No cousin. Explicit constructors or `CType` widening.

C / C++

No cousin. C++ user-defined literals (`operator""_tag`) are the closest analogue.
