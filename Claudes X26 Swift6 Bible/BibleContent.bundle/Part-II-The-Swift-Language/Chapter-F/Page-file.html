#file

Kind: directive

Definition

A magic literal that expands to the source file path where it appears. Useful in assertions and logging to identify the caller without hand-writing the filename.

Swift Example

func logHere(_ message: String, file: StaticString = #file, line: UInt = #line) {
    print("[\(file):\(line)] \(message)")
}

logHere("reached") // logs the file + line of the call site

Rosetta Stone

Pascal / Delphi

`{$I %FILE%}` compiler directive expands to the current source file.

BASIC

No cousin in VB; in C#/CallerFilePath attribute.

C / C++

`__FILE__` predefined macro — identical purpose.
