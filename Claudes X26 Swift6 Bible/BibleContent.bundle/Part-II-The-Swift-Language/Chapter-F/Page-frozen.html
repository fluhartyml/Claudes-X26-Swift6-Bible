@frozen

Kind: attribute

Definition

An attribute promising that the type's layout or set of cases won't change in future versions of the module. Lets the compiler make optimizations that would otherwise be unsafe across library-evolution boundaries.

Swift Example

@frozen public enum Either<A, B> {
    case left(A)
    case right(B)
}

let e: Either<Int, String> = .left(7)

Rosetta Stone

Pascal / Delphi

No cousin. Delphi doesn't have a library-evolution optimization annotation.

BASIC

No cousin.

C / C++

No cousin. Library ABIs in C are whatever the compiler emits; optimization decisions are per-call.
