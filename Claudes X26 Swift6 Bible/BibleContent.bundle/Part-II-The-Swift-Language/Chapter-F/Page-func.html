func

Kind: keyword

Definition

Declares a function — a named, reusable unit of code. Functions can take parameters, return a value, be generic, throw errors, be async, and accept trailing closures.

Swift Example

func greet(_ name: String, loud: Bool = false) -> String {
    let text = "hello, \(name)"
    return loud ? text.uppercased() : text
}

print(greet("Ada"))
print(greet("Max", loud: true))

Rosetta Stone

Pascal / Delphi

`function` (returns a value) vs `procedure` (no value). Two keywords instead of one.

BASIC

`Function f(x As Integer) As Integer` for value-returning; `Sub f(x)` for no return.

C / C++

`returnType name(args) { body }`. No keyword — the return type signals it's a function.
