for

Kind: keyword

Definition

Iterates over a sequence — arrays, ranges, strings, dictionaries, or anything conforming to `Sequence`. The `for-in` form binds each element to a constant; `for case` adds pattern matching.

Swift Example

for i in 1...5 { print(i) }

let names = ["Ada", "Max", "Zoe"]
for name in names where name.count > 2 { print(name) }

// for case — only iterate matching cases:
let results: [Result<Int, Error>] = [.success(1), .failure(NSError()), .success(3)]
for case .success(let v) in results { print(v) }
// 1
// 3

Rosetta Stone

Pascal / Delphi

`for i := 1 to 10 do` or `for element in collection do` (Delphi 2005+).

BASIC

`For i = 1 To 10` or `For Each element In collection`.

C / C++

`for (int i = 0; i < n; i++)`. C++ range-for: `for (auto &x : container)`. Swift's `for-in` reads like the range-for form.
