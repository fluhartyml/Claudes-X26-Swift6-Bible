Float

Kind: type

Definition

A 32-bit IEEE-754 floating-point type. Use `Double` by default; reach for `Float` only when memory or bandwidth for huge arrays of floats matters (e.g. graphics, audio buffers).

Swift Example

let x: Float = 1.5
let y: Float = 2.5
print(x + y) // 4.0

// Type context matters:
let whole: Float = 0.1 + 0.2 // still imprecise, just 32-bit

Rosetta Stone

`Single` in Pascal/Delphi — 32-bit IEEE 754 float.

BASIC

`Single` in VB.NET — same 32-bit float.

C / C++

`float` — same. All three are literally the IEEE 754 binary32 format.
