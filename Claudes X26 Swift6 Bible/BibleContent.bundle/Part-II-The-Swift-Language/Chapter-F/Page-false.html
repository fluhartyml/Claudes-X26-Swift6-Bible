false

Kind: literal

Definition

One of the two `Bool` literal values, representing logical falsehood. The other is `true`.

Swift Example

let isReady: Bool = false
if !isReady { print("keep waiting") }

Rosetta Stone

Pascal / Delphi

`False` — identical literal.

BASIC

`False` — identical literal.

C / C++

`false` (via `<stdbool.h>`) or `0` in older code. Identical meaning.
