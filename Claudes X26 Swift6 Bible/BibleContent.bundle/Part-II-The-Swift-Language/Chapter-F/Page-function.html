#function

Kind: directive

Definition

A magic literal that expands to the name of the enclosing function (or property, or initializer). Useful in logging, assertions, and tracing.

Swift Example

func doWork() {
    print(#function) // "doWork()"
}

doWork()

Rosetta Stone

Pascal / Delphi

No direct cousin. `{$I %FUNCTION%}` captures it in newer Delphi versions.

BASIC

No cousin; use `MethodBase.GetCurrentMethod().Name` at runtime.

C / C++

`__func__` (C99) and `__FUNCTION__` / `__PRETTY_FUNCTION__` (compiler-specific).
