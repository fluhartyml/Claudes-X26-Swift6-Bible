final

Kind: modifier

Definition

A class modifier that forbids subclassing the class, or overriding the marked member. Apply it whenever you don't intend a class to be extended — the compiler can then devirtualize calls for speed and the code reads as closed-for-extension.

Swift Example

final class Logger {
    func log(_ s: String) { print(s) }
}

// class Sub: Logger {} // error: inheritance from a final class

Rosetta Stone

Pascal / Delphi

`sealed` on a Delphi class prevents inheritance. `final` on methods prevents override.

BASIC

`NotInheritable` on a class; `NotOverridable` on a method.

C / C++

C++ `final` keyword (C++11) on classes and virtual methods. Same meaning.
