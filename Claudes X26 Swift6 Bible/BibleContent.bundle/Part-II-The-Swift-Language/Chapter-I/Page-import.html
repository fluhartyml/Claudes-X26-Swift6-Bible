import

Kind: keyword

Definition

Makes the public API of another module available in the current source file. Modules include Apple's frameworks (`Foundation`, `SwiftUI`), SwiftPM packages, and submodules inside the current app.

Swift Example

import Foundation
import SwiftUI

let now = Date()
print(now)

Rosetta Stone

Pascal / Delphi

`uses UnitA, UnitB;` in the unit header.

BASIC

`Imports System.Foo` at the top of a file.

C / C++

`#include <header.h>` (preprocessor). C++20 adds `import module;` which is closer to Swift's form.
