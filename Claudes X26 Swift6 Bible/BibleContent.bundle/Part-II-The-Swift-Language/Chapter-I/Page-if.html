if

Kind: keyword

Definition

Conditionally runs a block. Swift's `if` also has expression form — `let x = if cond { 1 } else { 2 }` — and combines with `let`/`var` for optional unwrapping and with `case` for pattern matching.

Swift Example

let n = 7
let label = if n > 0 { "positive" }
            else if n < 0 { "negative" }
            else { "zero" }
print(label) // positive

let maybe: Int? = 3
if let v = maybe { print(v) }

Rosetta Stone

Pascal / Delphi

`if cond then ... else ...` — same shape, requires `then`.

BASIC

`If cond Then ... Else ... End If`.

C / C++

`if (cond) { ... } else { ... }`. No `then` keyword, uses braces.
