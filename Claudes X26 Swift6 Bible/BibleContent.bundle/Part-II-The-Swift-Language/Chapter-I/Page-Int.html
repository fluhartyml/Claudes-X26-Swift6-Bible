Int

Kind: type

Definition

Swift's default signed integer type. Its size matches the platform's native word size (64-bit on modern Apple hardware). Use `Int` for indexes and counts unless you have a specific reason to pin a width.

Swift Example

let count: Int = 42
let sum = (1...100).reduce(0, +)
print(sum) // 5050

Rosetta Stone

Pascal / Delphi

`Integer` (32-bit on most targets) or `NativeInt` (matches pointer width — closer to Swift's Int).

BASIC

`Integer` is 32-bit in VB.NET; `Long` is 64-bit; `IntPtr` / `nint` matches pointer width.

C / C++

`int` (implementation-defined width, commonly 32-bit). Closer to Swift's Int: `intptr_t` from `<stdint.h>`.
