Identifiable

Kind: protocol

Definition

A protocol for types that have a stable `id`. SwiftUI's `ForEach`, `List`, and similar APIs use `Identifiable` so they can track elements across updates. Any `Hashable`, stable property can serve as the `id`.

Swift Example

struct Todo: Identifiable {
    let id: UUID = UUID()
    var title: String
}

let todos = [Todo(title: "buy milk"), Todo(title: "write book")]
// in a SwiftUI view:
// List(todos) { todo in Text(todo.title) }

Rosetta Stone

Pascal / Delphi

No cousin. Use a custom interface with a `GetID` method.

BASIC

No standard protocol. Implement `IIdentifiable(Of TKey)` by convention.
