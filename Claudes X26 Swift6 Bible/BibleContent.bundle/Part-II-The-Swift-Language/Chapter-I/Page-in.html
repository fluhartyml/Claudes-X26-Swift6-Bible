in

Kind: keyword

Definition

Separates a closure's signature from its body, and separates a loop variable from its sequence in `for-in`.

Swift Example

let squares = (1...5).map { n in n * n }
print(squares) // [1, 4, 9, 16, 25]

for name in ["Ada", "Max"] { print(name) }

Rosetta Stone

Pascal / Delphi

`for element in collection do` uses the same keyword.

BASIC

`For Each element In collection`.

C / C++

No keyword. C++ range-for uses `:` — `for (auto x : c)`.
