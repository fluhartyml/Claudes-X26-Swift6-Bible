@inlinable

Kind: attribute

Definition

An attribute that promises a public function's body won't change incompatibly, letting callers in other modules inline the body across module boundaries. Commonly used in small, hot-path library code.

Swift Example

@inlinable
public func clamp<T: Comparable>(_ x: T, min lo: T, max hi: T) -> T {
    return x < lo ? lo : (x > hi ? hi : x)
}

Rosetta Stone

Pascal / Delphi

`inline` directive on a function (`function f: Integer; inline;`) — suggests inlining.

BASIC

No user-facing attribute; JIT decides.

C / C++

`inline` keyword (C99). C++ adds `__attribute__((always_inline))` and `[[gnu::always_inline]]` for stronger hints.
