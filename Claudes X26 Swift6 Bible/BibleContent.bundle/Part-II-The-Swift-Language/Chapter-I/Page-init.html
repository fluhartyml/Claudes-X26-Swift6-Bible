init

Kind: keyword

Definition

A class / struct / enum initializer — the method that sets up a new instance. Swift checks that every stored property is initialized before the initializer returns. Initializers can throw, be `required`, `convenience`, or `failable` (`init?`).

Swift Example

struct User {
    let name: String
    let age: Int
    init(name: String, age: Int) {
        self.name = name
        self.age = age
    }
    init(anonymousWithAge age: Int) {
        self.init(name: "anonymous", age: age)
    }
}

Rosetta Stone

Pascal / Delphi

`constructor Create(...)` — same role. Delphi constructors are named `Create` by convention.

BASIC

`Sub New(...)` — the VB.NET constructor.

C / C++

No constructors in C. C++ uses `Foo() { ... }` with the class name as the method name.
