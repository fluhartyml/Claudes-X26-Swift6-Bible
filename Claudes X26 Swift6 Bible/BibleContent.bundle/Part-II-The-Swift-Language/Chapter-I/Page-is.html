is

Kind: keyword

Definition

A runtime type-check operator. `value is Type` returns `true` when `value` is an instance of `Type` (or a subclass, or a type conforming to the protocol).

Swift Example

let items: [Any] = [1, "two", 3.0]
let strings = items.filter { $0 is String }
print(strings.count) // 1

if items[1] is String { print("element 1 is a String") }

Rosetta Stone

Pascal / Delphi

`obj is TSub` — identical runtime type test.

BASIC

`TypeOf obj Is T`.

C / C++

No runtime type info in C. C++ uses `dynamic_cast<T*>(p) != nullptr` or `typeid(x) == typeid(T)`.
