inout

Kind: keyword

Definition

Marks a function parameter as pass-by-reference: the function can mutate it, and the change is visible to the caller after the call returns. At the call site, prefix the argument with `&`.

Swift Example

func doubleIt(_ n: inout Int) {
    n *= 2
}

var x = 5
doubleIt(&x)
print(x) // 10

Rosetta Stone

Pascal / Delphi

`var` parameter: `procedure f(var x: Integer)`. Pass-by-reference; caller writes `f(myVar)`.

BASIC

`ByRef x As Integer` parameter. Same semantics.

C / C++

Pass a pointer: `void f(int *x)`; call site `f(&myVar)`. C++ adds `int&` reference parameters.
