internal

Kind: access-level

Definition

The default access level — a declaration is visible everywhere in the module that declares it, and invisible from the outside. You rarely write `internal` because it's implicit.

Swift Example

// Inside MyLib.swift (module MyLib)
internal struct Cache { var items: [String] = [] }
// Equivalent:
struct Cache2 { var items: [String] = [] }

Rosetta Stone

Pascal / Delphi

Delphi has no exact cousin. `private`/`protected`/`public` are the access levels; units don't export what they don't list in the `interface` section.

BASIC

`Friend` — visible within the assembly, hidden outside.

C / C++

No access modifiers in C. C++ `public`/`protected`/`private` apply to class members, not modules.
