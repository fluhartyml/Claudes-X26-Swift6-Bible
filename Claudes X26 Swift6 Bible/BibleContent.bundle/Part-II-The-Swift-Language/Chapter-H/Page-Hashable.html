Hashable

Kind: protocol

Definition

A protocol for types that can produce an integer hash value, which lets them be used as Dictionary keys, Set members, and in any context needing content-based identity. Swift synthesizes conformance for value types whose properties are all `Hashable`.

Swift Example

struct Coord: Hashable { let x, y: Int }

var visited: Set<Coord> = []
visited.insert(Coord(x: 0, y: 0))
visited.insert(Coord(x: 0, y: 0)) // duplicate — no-op
print(visited.count) // 1

Rosetta Stone

Pascal / Delphi

No direct cousin. Delphi's `TDictionary<K, V>` requires a `TEqualityComparer<K>` or it defaults to `THashService`.

BASIC

`IEquatable(Of T)` plus `Overrides Function GetHashCode() As Integer`.

C / C++

No cousin in C. C++ specializes `std::hash<T>` for the key type used in `std::unordered_map`.
