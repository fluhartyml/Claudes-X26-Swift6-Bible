@UIApplicationMain

Kind: attribute

Definition

A legacy attribute on a UIKit `UIApplicationDelegate` that marks it as the app's entry point. Superseded by `@main` + `UIApplicationDelegateAdaptor` in SwiftUI lifecycles; still seen in UIKit-only apps.

Swift Example

import UIKit

@UIApplicationMain
class AppDelegate: UIResponder, UIApplicationDelegate {
    func application(_ app: UIApplication,
                     didFinishLaunchingWithOptions opts: [UIApplication.LaunchOptionsKey: Any]?) -> Bool {
        true
    }
}
