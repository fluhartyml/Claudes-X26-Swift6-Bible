Bool

Kind: type

Definition

The Boolean type — a value that is either `true` or `false`. It's the type of every condition Swift's control flow statements read (`if`, `while`, `guard`), and the result of comparison and logical operators.

Swift Example

let isRaining = true
let hasUmbrella = false

if isRaining && !hasUmbrella {
    print("get wet")
} else {
    print("you're fine")
}
