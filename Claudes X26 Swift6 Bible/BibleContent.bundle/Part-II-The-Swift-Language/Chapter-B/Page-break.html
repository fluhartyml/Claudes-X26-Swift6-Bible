break

Kind: keyword

Definition

A control-flow statement that exits the enclosing loop or switch immediately. Inside nested loops, you can break to a labeled loop to exit more than one level at once.

Swift Example

for n in 1...10 {
    if n == 5 { break }
    print(n)
}
// prints 1 2 3 4

outer: for row in 0..<3 {
    for col in 0..<3 {
        if row == col { break outer }
    }
}
