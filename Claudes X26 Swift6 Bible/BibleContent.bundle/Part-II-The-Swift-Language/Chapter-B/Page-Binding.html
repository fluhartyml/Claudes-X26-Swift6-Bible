@Binding

Kind: attribute-swiftui

Definition

A SwiftUI property wrapper that creates a two-way connection to a value owned elsewhere — typically a `@State` in a parent view. Writing through a `@Binding` updates the source of truth, and the binding's reads always reflect the current source value.

Swift Example

struct Toggle2: View {
    @Binding var isOn: Bool
    var body: some View {
        Button(isOn ? "On" : "Off") { isOn.toggle() }
    }
}

struct Parent: View {
    @State private var on = false
    var body: some View { Toggle2(isOn: $on) }
}

Rosetta Stone

Pascal / Delphi

No cousin. Delphi's LiveBindings are the spiritual match: declarative two-way binding between a UI component and a property.

BASIC

WPF's `{Binding Path=...}` with `Mode=TwoWay`. Same concept, different wiring.

C / C++

No cousin. Callback-based observers are the manual equivalent.
