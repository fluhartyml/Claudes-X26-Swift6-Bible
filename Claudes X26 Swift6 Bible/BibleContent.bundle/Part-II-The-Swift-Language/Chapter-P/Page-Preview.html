#Preview

Kind: macro

Definition

A freestanding macro (Xcode 15+) that declares a SwiftUI preview without boilerplate. Multiple `#Preview` blocks can sit in one file, each showing a different configuration.

Swift Example

import SwiftUI

struct Hello: View {
    var body: some View { Text("hi") }
}

#Preview { Hello() }
#Preview("Dark") { Hello().preferredColorScheme(.dark) }

Rosetta Stone

Pascal / Delphi

Delphi's form designer is the WYSIWYG equivalent — no code macro, but live preview of a TForm.

BASIC

WPF / Blazor hot-reload previews show the component live during editing.
