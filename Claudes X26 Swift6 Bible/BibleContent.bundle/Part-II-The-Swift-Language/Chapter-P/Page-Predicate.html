#Predicate

Kind: macro

Definition

A freestanding macro (Swift 5.9+) that builds a `Predicate<Input>` — a structured, introspectable filter expression — from a closure-like body. Used with SwiftData, CoreData via interop, and generic predicate-aware APIs.

Swift Example

import Foundation

struct Item { let name: String; let price: Double }

let cheap = #Predicate<Item> { $0.price < 10 }
let items = [Item(name: "pen", price: 2), Item(name: "chair", price: 50)]
let matches = try items.filter { try cheap.evaluate($0) }
print(matches.count) // 1

Rosetta Stone

Pascal / Delphi

No cousin. LINQ-style predicate lambdas (`function(x: T): Boolean`) are the runtime equivalent but not introspectable.

BASIC

`Expression(Of Func(Of T, Boolean))` — an introspectable predicate tree. Closest cousin.
