public

Kind: access-level

Definition

An access level that makes a declaration visible from outside the module but not subclassable or overridable unless you also mark it `open`. Use `public` for library API that callers may use but shouldn't extend.

Swift Example

public struct Point {
    public let x, y: Double
    public init(x: Double, y: Double) {
        self.x = x; self.y = y
    }
}

Rosetta Stone

Pascal / Delphi

`public` visibility in a class — identical meaning.

BASIC

`Public` access modifier.

C / C++

No modifier at file scope (everything not `static` is external). C++ `public:` on class members.
