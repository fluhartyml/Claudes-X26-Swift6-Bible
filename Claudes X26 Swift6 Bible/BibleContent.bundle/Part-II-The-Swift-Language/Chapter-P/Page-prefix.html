prefix

Kind: keyword

Definition

Declares that a custom operator appears before its operand (like `!` in `!bool` or `-` in `-5`). Needed alongside the operator-function declaration.

Swift Example

prefix operator ¬

prefix func ¬ (b: Bool) -> Bool { !b }

print(¬true) // false

Rosetta Stone

Pascal / Delphi

Prefix operators in Delphi are the built-ins (`not`, `-`, `+`). User-defined operators use `class operator` syntax.

BASIC

Built-in prefix operators only; overloadable via `Shared Operator`.

C / C++

C/C++ unary operators like `-x`, `!x`, `++x` are prefix. Overloadable in C++: `T operator-() const;`.
