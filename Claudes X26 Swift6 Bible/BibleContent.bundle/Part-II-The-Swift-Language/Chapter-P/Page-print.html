print

Kind: function

Definition

Writes its arguments to standard output, followed by a newline by default. Each argument is stringified via its `String(describing:)` form. Handy for quick debugging and console tools.

Swift Example

print("hello")
print("x =", 42)
print("joined", "words", separator: "-") // joined-words
print("no newline", terminator: "")
print(" continued")

Rosetta Stone

Pascal / Delphi

`WriteLn('hello')` writes to stdout.

BASIC

`Console.WriteLine("hello")` or classic `Print "hello"`.

C / C++

`printf("hello\n")` — format-string based. C++ adds `std::cout << "hello" << std::endl;`.
