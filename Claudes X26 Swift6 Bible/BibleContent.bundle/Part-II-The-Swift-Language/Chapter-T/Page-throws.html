throws

Kind: keyword

Definition

A modifier on a function declaration saying the function may throw an error. Callers must use `try` (or `try?` / `try!`) and handle or propagate the error.

Swift Example

func parse(_ s: String) throws -> Int {
    guard let n = Int(s) else {
        throw NSError(domain: "parse", code: 1)
    }
    return n
}

let n = try? parse("42") // Optional(42)
let bad = try? parse("nope") // nil

Rosetta Stone

Pascal / Delphi

No cousin. Every Delphi function can raise; no declaration required.

BASIC

No cousin. No checked exceptions in VB.NET.

C / C++

No cousin. C++ had `throw()` specifications (deprecated) and `noexcept` (inverse — marks non-throwing).
