Task

Kind: type

Definition

A unit of asynchronous work. `Task { ... }` runs the block on a task separate from the current one; the task has a priority, a cancellation flag, and produces a `Task<Value, Error>` handle you can `await`.

Swift Example

let t = Task {
    try await Task.sleep(nanoseconds: 100_000_000)
    return "done"
}

Task {
    let v = try await t.value
    print(v) // done
}

Rosetta Stone

Pascal / Delphi

`TTask` from System.Threading — `TTask.Run(...)` starts one; `.Wait` / `.Result` resolve it.

BASIC

`Task.Run(...)` in VB.NET — same API as C#.

C / C++

`std::thread` for coarse threading; C++20 `std::jthread`. Coroutines via `co_await` on a coroutine return type.
