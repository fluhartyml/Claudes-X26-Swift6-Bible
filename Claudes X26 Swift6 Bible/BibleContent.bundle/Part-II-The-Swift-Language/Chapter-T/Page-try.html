try

Kind: keyword

Definition

Marks a call site where the called function may throw. Flavors: `try` inside a `do/catch` propagates the error to `catch`, `try?` converts to an Optional (nil on throw), and `try!` traps if the call throws.

Swift Example

func mayThrow() throws -> Int { 42 }

do { print(try mayThrow()) }
catch { print(error) }

let opt = try? mayThrow()  // Optional(42)
let forced = try! mayThrow() // 42, or crash

Rosetta Stone

Pascal / Delphi

`try ... except on E: ... do ... end;` for throwing calls. No per-call `try` marker — all Delphi calls can implicitly raise.

BASIC

`Try ... Catch ... End Try` block. No per-call `Try` marker either.

C / C++

No cousin in C. C++ `try { call(); } catch (...)` — also no per-call marker.
