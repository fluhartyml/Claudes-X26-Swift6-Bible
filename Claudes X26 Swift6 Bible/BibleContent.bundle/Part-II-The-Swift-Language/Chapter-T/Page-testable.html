@testable

Kind: attribute

Definition

An attribute on `import`, written `@testable import MyModule`, that exposes the module's `internal` declarations to the importing (test) module. Use only in test targets.

Swift Example

// In MyAppTests/SomeTests.swift:
@testable import MyApp

final class MyTests: XCTestCase {
    func testInternalThing() {
        // Can call internal helpers of MyApp here.
    }
}

Rosetta Stone

Pascal / Delphi

No cousin. Delphi has no assembly-scope separation; tests import units normally.

BASIC

`<InternalsVisibleTo("MyTests")>` attribute on the assembly achieves the same thing.
