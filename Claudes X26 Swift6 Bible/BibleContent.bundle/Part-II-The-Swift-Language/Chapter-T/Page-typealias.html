typealias

Kind: keyword

Definition

Introduces a new name for an existing type — useful for shortening long generic types, documenting intent, or making signatures read more naturally.

Swift Example

typealias Meters = Double
typealias Handler = (Result<Data, Error>) -> Void

let distance: Meters = 1500

func fetch(_ done: Handler) { /* ... */ }

Rosetta Stone

Pascal / Delphi

`type TMyList = TList<Integer>;` — an identical type-rename.

BASIC

`Imports MyList = System.Collections.Generic.List(Of Integer)` — scoped rename.

C / C++

`typedef int (*Handler)(void *);` — the C type-renaming keyword. C++ `using Handler = ...` is more modern.
