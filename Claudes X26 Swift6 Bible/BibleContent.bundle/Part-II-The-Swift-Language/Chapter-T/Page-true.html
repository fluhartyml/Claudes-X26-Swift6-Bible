true

Kind: literal

Definition

One of the two `Bool` literal values, representing logical truth. The other is `false`.

Swift Example

let isReady: Bool = true
if isReady { print("go") }

Rosetta Stone

`True` — identical literal.

C / C++

`true` (via `<stdbool.h>`) or `1`.
