JSONDecoder

Kind: type

Definition

A Foundation class that reads JSON `Data` back into an `Decodable` type. Configure how it interprets dates, keys, and raw numbers once, then reuse. The dual of `JSONEncoder`.

Swift Example

import Foundation

struct User: Codable { let id: Int; let name: String }

let json = #"{ "id": 7, "name": "Ada" }"#.data(using: .utf8)!
let user = try JSONDecoder().decode(User.self, from: json)
print(user.name) // Ada
